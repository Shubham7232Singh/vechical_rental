# Vehicle Rental

A vehicle rental application for browsing, booking, and managing rental vehicles.

## Features

- Browse available vehicles
- View vehicle details and rental prices
- Search and filter vehicles
- Register and manage customer accounts
- Create and manage rental bookings
- Update vehicle availability
- Admin management for users, vehicles, and bookings
